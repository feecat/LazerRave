# 桌面客户端

## 实现结构

`src/LazerRave/lazer/` 提供 LazerRave 桌面入口，继承经过裁剪的 osu!lazer `OsuGame`，复用菜单、工具栏、选曲、字体、动画和设置。资源加载与着色器预编译后直接进入主菜单，退出不播放结束动画。

`src/LazerRave/engine-bridge/` 负责曲库协议、媒体预览和 Windows 原生窗口承载。演奏使用独立 OpenLR2 进程，前端与引擎有各自的绘制循环。

## 曲库与设置

客户端按文件夹层级展示 BMS，支持键型、难度、搜索与预览。所选谱面、速度、判定偏移和排列通过桥接传入引擎。客户端与经典模式使用设置中同一组曲库根目录；同步与编码行为见 [引擎桥接](engine-bridge.md)。

选曲底部提供判定槽、速度和轨道入口，分别显示当前槽类型、速度倍率和排列方式。弹出菜单沿用客户端圆角浮层、配色和动画，包含判定槽、速度、轨道、其他和扩展五个分页。63 个具名演奏选项与既有速度、偏移、排列一起保存到 TOML；重新扫描保留在曲库设置的应用入口。经典 OpenLR2 菜单继续保留。

MANIAC 扩展沿用引擎行为，部分扩展不包含在 LR2 回放记录中。Ghost Battle 标注为经典菜单功能，前端阻止在未选择对手时直接开始该模式。回放入口复用 LR2 输入记录与随机种子，正常演奏按次保存；回放观看不产生新成绩。MANIAC 和辅助模式记录为练习，不进入最高分或上传排行，未完整记录参数的扩展模式不生成前端回放。IR 演奏目标仍由引擎及其已有数据处理。

曲包及子曲包以金色文件夹图标和色条显示，点击进入下一层。仅包含某首歌曲谱面的目录直接显示为一条曲目，无需进入该目录；同一目录的谱面保留为该曲目的难度选项。当前层只显示直接所属曲目和下一层曲包，不平铺更深层曲目。排序不会拆开曲目的难度。左上角提供可点击的路径导航，返回键逐层返回；多个根目录可从曲库总览选择。

前端设置保存到 EXE 同级的 `userdata/settings.toml`，语言和主题相关设置由保留的客户端设置系统管理，客户端配置与数据库同样位于 `userdata/`。缓存保存于 EXE 同级的 `cache/`。首次正常启动从旧 AppData 位置复制持久数据，保留旧数据且不覆盖目标文件。新增演奏参数停止修改约 400 ms 后自动保存，开始演奏前再次保存；失败时显示错误并阻止使用旧参数启动。

曲库设置提供逐条添加、编辑和移除目录的列表。默认目录为 EXE 同级的 `BMS/`；相对路径以 EXE 所在目录解析，保存时保留相对形式。绝对路径与相对路径指向同一目录时去重，向引擎同步时统一使用绝对路径。多人下载目录 `Shared/` 自动纳入曲库。

没有已有配置时，前端以 1920×1080 窗口启动，绘制帧率限制为固定 240 FPS；演奏默认同窗口、1920×1080、E（D3D11 blit）预设和 240 FPS。已有窗口、渲染及帧率配置继续保留。图形设置支持固定帧率、显示器同步及无限制，前端固定值保存于 `frontend_frame_limit`。

顶部工具栏显示 LazerRave 品牌，网站、下载及 GitHub 三个外链入口使用系统浏览器打开对应页面；保留账户、时钟及通知。客户端未集成内置浏览器。原有空谱面播放器和未接入的官方导航不显示，主菜单曲名提示条不展示占位谱面。通用设置不显示快捷操作；输入设置仅保留受支持设备。

上游图形、音频、输入及皮肤设置作用于 C# 客户端。OpenLR2 的演奏设置由原生配置与桥接参数共同决定。客户端默认英语，新增主要文本覆盖英语、简体中文和日语；亮色主题、完整本地化及 DPI 矩阵尚未完成。

## 谱面、成绩与回放

osu! 星级与 PP 自动计算暂时关闭。曲目列表和成绩提示不启动难度计算任务；BMS 原有难度类别、`Lv.` 等级及范围筛选继续保留。

曲目时长从 BMS 时间轴读取，计入初始 BPM、BPM 变化、STOP、小节倍率及长音符末端，显示到谱面最后一个演奏／背景事件。包含随机分支的谱面使用固定分支读取曲库元数据，实际演奏可因分支选择而变化。排行评级沿用 OpenLR2：以 `EX SCORE × 9 ÷ 满分` 的整数结果对应 AAA、AA、A、B、C、D、E、F，满分仍显示 AAA。

选曲左侧默认显示排行，复用上游成绩列表、个人最佳区域、列表动画、本地／全局切换和排序控件。谱面与难度继续由右侧曲目列表选择。键型筛选保留现有控件；难度筛选复用原有双端范围滑条，按 BMS 的整数 `Lv.` 等级过滤，默认不限制等级。

输入搜索文本后，在全部配置目录中检索标题、作者、目录及谱面文件名。清空搜索恢复原文件夹层级；返回键优先清空搜索，再返回父目录。空搜索时仍按目录展开，不平铺整个曲库。

完成的演奏记录保存于 `userdata/play-records/scores/<谱面 SHA-256>/<会话标识>.xml`，回放保存于 `userdata/play-records/replays/<会话标识>.lr2rep`。记录包含 EX SCORE、普通 SCORE、判定数量、最大连击、MISS、通过状态、玩家、时间、排列与判定槽。排行与个人最佳以 EX SCORE 展示，普通 SCORE 保存在演奏记录中；自动演奏、辅助、MANIAC 与中断会话不影响正常最高分。文件内容未改变时，移动曲库目录不影响记录关联。原有 LR2 成绩与回放继续通过经典档案读取。

网络排行使用现有 LazerRave 服务，按谱面内容哈希匹配已发布曲库，并按排列与判定槽查询，当前列表显示前 50 条成绩，切换谱面或排行范围时刷新。读取排行不要求登录；上传成绩需要登录并从成绩右键菜单选择上传，只接受正常演奏和已收录谱面，重复上传同一会话不会产生重复成绩。成绩有本地回放时，点击成绩或从其右键菜单选择观看回放。客户端未上传谱面回放至云端。

## 演奏方式

| 模式 | 行为 |
| --- | --- |
| Embedded / 同窗口 | 将原生游戏窗口承载于客户端，使用所选同窗口渲染预设与引擎帧率上限 |
| Separate window / 独立窗口 | 打开独立 OpenLR2 窗口，直接演奏所选谱面，保留经典渲染与同步配置 |
| 经典入口 | 直接运行 `OpenLR2_x64.exe`，保留经典菜单 |

演奏方式、窗口预设和自定义宽高自动保存。独立模式不应用同窗口的 A～G 预设。旧皮肤的内部逻辑画布与窗口尺寸分别处理，放大窗口不会补充素材细节。

同窗口首次默认采用 E 预设（D3D11 blit），关闭引擎 VSync；A～G 预设可在设置中切换。引擎帧率支持 Display、固定数值和 Unlimited；前端绘制遵循自身图形设置。对比方法与日志定义见 [BGA 与帧时间](bga-diagnostics.md)。

## 组件复用与裁剪

新闻、更新日志、在线搜谱、用户资料、通用认证、房间、聊天、排行榜和回放组件继续保留。账户、房间列表、参与玩家和房间聊天已接入 LazerRave 服务；大厅复用原有 OnlinePlayScreen 和 LoungeSubScreen，房间页沿用原三栏布局。osu! API 提供者保持离线，远程纹理仅允许当前 LazerRave 服务器的头像接口。其他保留页面与请求类不表示相应在线服务已接入。

osu!、Taiko、Catch、欢迎及结束动画、设置向导、皮肤布局编辑器、官方排位活动、每日挑战和歌单专用界面已裁剪。Kudosu、每日挑战个人统计、制谱订阅数、supporter 标识和部分无调用的官方专用请求也已移除。

客户端不注册 `.osz`、`.olz`、`.osr` 导入，不支持 `.osu` 谱面解析及导出。Mania 用于 BMS 元数据接口，不将 BMS 转换为 Mania 演奏。星级当前为占位，卡片中的 `Lv.` 是 BMS 等级，最佳 EX SCORE 独立显示。

数位板、系统笔、相对鼠标、触屏、摇杆和 MIDI 输入由客户端策略禁用，普通鼠标、键盘和滚轮保留。该策略仅作用于前端，不修改 OpenLR2 的设备配置。框架二进制包仍可能包含未启用的设备实现。

## 编辑器基础

保留时间轴、撤销重做、谱面属性、校验框架及 Mania 音符和长音符工具。当前不开放编辑入口，不支持 BMS 编辑或保存。后续需要 BMS 编辑模型、资源引用、编码保存和往返校验；官网上传模块保持移除。

## 运行与发行边界

运行 `out/app/LazerRave.exe`，须保留整个目录。启动异常记录于 `userdata/logs/lazer-startup-error.txt`；无法写入时尝试 EXE 同级的同名文件。构建与检查工具说明见 [验证范围](verification.md)。

发行构建采用 .NET 自包含托管单文件发布，不启用 trimming。主程序和一般托管依赖合入 EXE，裁剪后的素材程序集外置于 `Resources/osu.Game.Resources.dll`；第三方原生依赖与 OpenLR2 保持外置。语言卫星程序集保留全部文化版本，统一发布到 `Localization/<culture>/`。发布依赖清单同步记录外置路径，`RuntimeResources` 提供按程序集名称解析的回退；缺少翻译时继续使用标准父文化及中性资源回退。规则集按程序集名称去重，版本指纹支持程序集没有独立文件路径的情况。

资源裁剪由独立构建工具执行，保留原有代码接口和程序集身份，不改写 NuGet 缓存或开发输出。策略、保留范围和报告位置见 [资源包](resource-pack.md)。

PDB、链接库、生成的 API XML 文档和 ExampleIR 不进入运行包。`out/build/` 中的常规开发输出仍保留独立程序集与调试文件，供 IDE 调试使用。单文件发布减少根目录文件数量，不代表删除相应功能或显著缩小资源程序集。

账号、最多 16 人联机、云端回放、曲包服务、BMSON、段位认证和 Steam 接入见 [路线图](../roadmap.md)。现有接口需要适配自有身份、谱面与成绩模型，不能仅修改官方 API 地址完成接入。

上游代码、资源、字体与品牌分别遵循各自许可。`licenses/` 随运行包提供声明；公开发行前须完成素材替换、依赖审计与干净设备验收。
