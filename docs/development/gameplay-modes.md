# 演奏模式与设置

LazerRave 在选曲页配置演奏参数，由 OpenLR2 执行谱面加载、判定、绘制、成绩与回放。前端使用现有选曲界面的弹出菜单，不另设独立演奏界面。

## 当前功能

选曲页底部提供判定槽、下落速度和轨道排列三个入口。入口显示当前选项，展开后共用五个选项卡：

| 选项卡 | 内容 |
| --- | --- |
| Gauge | 1P/2P 判定槽、BATTLE 模式、自动演奏、自动键音、自动刮盘与判定槽自动切换 |
| Speed | 1P/2P 下落速度、BPM 参考、基础速度、速度上下限、步进与方向键调速开关 |
| Lanes | 六种排列、HIDDEN/SUDDEN、遮挡、LIFT、DP FLIP、随机排列中的刮盘与固定轨道 |
| More | BGA、判定偏移、判定自动调整、分数参照、目标、回放保存与鼠标退出开关 |
| Modifiers | 原有 MANIAC 扩展，包括加速、软着陆、增加音符、长条、地雷与视觉扰动 |

参数保存在 `userdata/settings.toml`，其中下落速度、判定偏移和 1P 排列保留原有字段，其余 63 个整数参数位于 `[play]` 表。旧配置缺失的字段使用前端默认值，保存时保留未知字段。设置在下一次演奏开始时生效。

排列提供 OFF、MIRROR、RANDOM、S-RANDOM、SCATTER、CONVERGE；判定槽提供 NORMAL、HARD、DEATH、EASY、P-ATTACK、G-ATTACK。具体数值范围和默认值以 `src/LazerRave/engine-bridge/PlayOptions.cs` 为准，引擎字段映射以 `src/OpenLR2/LR2/LR2_launcher_options.inc` 为准。

重新扫描入口保留在设置中。主菜单的“原生 LR2”位于设置按钮右侧、主图标左侧，可通过 N 键启动。入口使用随包 `OpenLR2_x64.exe` 及运行目录，不附加直达谱面的请求，保留原生选曲、键位、皮肤和课程菜单。经典进程运行期间暂停前端预览、嵌入演奏、多人入口及曲库扫描。

## 原生 LR2 配置

设置中的“原生 LR2”直接读取 `LR2files/Config/config.xml` 和 `openlr2-config.xml`，提供以下分组：

| 分组 | 设置 |
| --- | --- |
| 原生显示 | 全屏、窗口、无边框全屏与垂直同步 |
| LR2 音频 | WASAPI / ASIO、设备名称、缓冲区大小与数量、总音量、BGM 音量和键音音量 |
| 原生输入与曲库 | 输入释放延迟、Windows 键、自动刷新、选曲预览与日志 |
| LR2 皮肤 | 各键型演奏皮肤、选曲、加载、结果、音效包、字体及原生配置目录 |

窗口尺寸复用“游戏窗口”的预设和自定义尺寸；曲库复用“曲库”的目录列表，包含相对路径及 `Shared`。启动原生模式前，将尺寸、目录、1P 速度、偏移、排列及原生配置能够持久化的判定槽、遮挡、BGA、目标分数、回放保存等选项同步到引擎配置。双人及 MANIAC 等没有对应持久化字段的选项仍按各自入口处理，不伪造原生配置字段。

原生音频设置作用于 OpenLR2，前端预览音量由“前端音频”管理。当前引擎将原 LR2 的 DirectSound 配置按 WASAPI 执行，因此该兼容值明确标注为 WASAPI。设备列表通过随包 FMOD 枚举。皮肤与音效包使用现有界面的文件选择器，筛选 `.lr2skin` 或 `.lr2ss`，选择后保存相对于运行目录的路径；更换路径时校验文件存在，原有路径不主动重置。键位及皮肤自定义选项继续使用原生菜单。

保存仅更新修改的字段，保留未知节点、原生账号及网络配置，不修改成绩数据库或键位文件。XML 按引擎使用的 CP932 编码写入；无法直接编码的字符使用 XML 字符引用。保存前验证待修改的配置文件，写入临时文件后替换，并保留 `.lazerrave.bak`。原生进程退出后重新读取原生设置；游戏或扫描运行期间暂缓写入。配置不可读取时显示保存错误，可在修复文件后使用“重新读取原生配置”。

## 参数语义

- 下落速度只控制音符滚动，不改变歌曲音频速度。桥接中的 `speed` 和 `speed2` 使用倍率乘以 100 的整数；2.75× 对应 275。
- 基础速度使用百分比；速度上下限和步进同样采用倍率乘以 100 的整数。最小值不得超过最大值。
- BPM 参考提供 OFF、MAX BPM、MIN BPM、AVERAGE BPM、CONSTANT、MAIN BPM。CONSTANT 沿用引擎的渲染时间轴转换，不等同于 OFF；引擎保留对变 BPM 谱面及特殊排列的判定槽限制。
- 遮挡、LIFT 与百分比扩展沿用 LR2 原有单位。固定轨道的有效范围取决于当前键型，引擎沿用原有约束。
- 回放保存提供 OFF、ALL、BEST SCORE、CLEAR、FULL COMBO，依照引擎原有保存条件执行。

协议根版本仍为 `version="1"`，新增能力标识为 `LAZERRAVE_PLAY_OPTIONS_V1`。客户端在发送演奏请求前检查引擎能力。引擎拒绝未知、重复、非整数及越界选项，并在应用部分请求后再次检查有效速度上下限。未携带 `play-options` 的旧请求保持原有直达行为。协议细节见 [引擎桥接](engine-bridge.md)。

## 当前边界

GHOST BATTLE 需要经典菜单中的对手与回放选择，前端直达入口会拒绝该模式并提示使用经典菜单。演奏选项中的 IR 目标分数沿用引擎原有数据来源，尚未绑定本站排行。客户端已接入自有账户、网络排行和多人房间。

自动演奏禁用成绩写入。MANIAC 等扩展的成绩与回放限制由 OpenLR2 决定；配置字段成功传入不代表所有组合均能保存成绩。前端不修改现有成绩数据库或回放格式。

嵌入演奏的 `no-bga` 渲染预设优先于 BGA 选项。游戏窗口和原生音频、皮肤使用上述设置；键位及皮肤自定义选项由原生菜单管理。

无窗口检查覆盖参数持久化、六种排列及 63 个字段的引擎应用结果。实际滚动、特殊模式、成绩保存、回放还原及键型组合仍需人工演奏验收，见 [编译与验证范围](verification.md)。

## 后续工作

| 工作 | 前置条件 |
| --- | --- |
| 具名演奏预设与每谱面覆盖 | 明确全局、谱面和会话设置的优先级，扩展 TOML 配置 |
| 前端回放入口与 GHOST BATTLE 对手选择 | 读取并校验回放元数据，接入经典回放准备流程 |
| 音频变速与保持音高选项 | 统一音频、谱面时间轴和判定，校验现有 FMOD 路径 |
| 模式组合的成绩标识与云端排行 | 定义规则版本、谱面与模式组合标识，明确排名条件 |
| 回放兼容扩展 | 逐项核对参数和随机种子的记录、还原，建立固定样本 |
| 演奏中前端调节参数 | 增加会话命令通道，定义允许实时变更的参数 |

现有回放记录包含随机种子及部分排列、辅助、BATTLE、HS 固定参数。未来新增影响判定或谱面内容的选项必须具备完整的记录与还原能力，并检查异版本兼容性。音频变速不能直接等同于下落速度，也不能在未经判定与回放验证前作为排名模式发布。
