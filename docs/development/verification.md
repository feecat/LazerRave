# 编译与验证范围

## 编译与文档

```powershell
.\build.cmd -CompileOnly
python -X utf8 -B scripts/check_docs.py
python -m mkdocs build --strict
```

编译入口构建客户端与所需原生引擎，不启动应用或测试，日志位于 `out/logs/`。文档检查覆盖配置、完整导航、本地链接与锚点；MkDocs 输出到 `out/site/`。编译、数据检查和实际游玩分别记录，不能相互替代。

## 独立检查工具

| 工具 | 范围 |
| --- | --- |
| `scripts/check.ps1` | 文档入口，测试和编译由显式参数启用 |
| `scripts/tests/` | 构建与打包规则、玩家数据保留、引擎桥接及帧时间分析 |
| `LazerRave.exe --check report.txt` | BMS 分组、参数保存、原生选项映射及裁剪边界 |
| `src/Cloud/tests/` | 账户、IR、房间、传输、目录安装及部分客户端适配 |
| `src/Cloud/web/tests/` | 独立数据库的 HTTP/SignalR 与无窗口浏览器检查 |
| `scripts/performance/` | 显式启动的游戏窗口、自动演奏与帧时间诊断 |

引擎集成检查需显式提供 `LAZERRAVE_TEST_ENGINE` 和 `LAZERRAVE_TEST_FMOD`。网站集成检查仅使用独立测试数据库，性能诊断使用隔离运行目录。正常构建不调用这些工具。

## 既有验证范围

截至 2026-10-10，已记录客户端和原生引擎编译、发布包完整性、IR 范围权限与演奏时间、迁移 6–9、同曲难度分组、共享安装与迁移、曲包目录、网页列表和页码交互等检查。BMS 元数据检查覆盖自定义难度标签、谱面身份及键型；发布检查覆盖默认配置、个人数据排除与 ZIP 校验。

这些结果对应各次修改时的版本，不表示所有接口在每次编译中都会重测。具体重现工具维护于上表，临时数据库、日志和诊断副本放在忽略目录。

## 人工验收与未验证项

| 范围 | 需要确认的行为 |
| --- | --- |
| 曲目预览，音频仍未人工验证 | 启动随机播放、完整曲目与尾音、播完换歌、选曲切换、演奏时停止预览 |
| 本地游玩 | 目录层级、难度与选项、设置持久化、完整演奏和退出 |
| 呈现与输入 | 图片与视频 BGA、鼠标键盘、窗口恢复、多屏和 DPI |
| 多人完善 | 双真机同步、加载失败、后台客户端、断网和结果一致性 |
| 发行 | 干净设备解压启动、更新保留账号、成绩、回放及自定义资源 |

无窗口检查和前端 FPS 不能代替实际呈现验收。验收矩阵见 [质量标准](../compatibility/quality.md)，完整帧时间记录见 [BGA 诊断](bga-diagnostics.md)。
