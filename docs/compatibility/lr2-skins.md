# LR2 皮肤扩展参考

本文记录当前 OpenLR2 继承的皮肤扩展及编号。编号含义与旧皮肤兼容层保持一致，实际覆盖范围由 [皮肤兼容矩阵](quality.md) 验证。

## 画布与分辨率

`#INFORMATION` 在原有字段后增加可选宽高：

```text
#INFORMATION,{type},{title},{maker},{thumbnail},
#INFORMATION,{type},{title},{maker},{thumbnail},{width},{height}
```

`#RESOLUTION` 声明预设逻辑分辨率：

| 值 | 预设 |
| --- | --- |
| `0` | SD，480p |
| `1` | HD，720p |
| `2` | Full HD，1080p |
| `3` | Ultra HD，2160p |

```text
#RESOLUTION,2
```

逻辑画布与实际窗口客户区分别管理。窗口调整工具不自动改写皮肤画布。

## 显示条件 `dst_option`

| 编号 | 含义 |
| --- | --- |
| `626` | 显示导入成绩 |
| `270` | 游玩场景的遮挡数值显示条件；保留 Sudden+ 行为，并在 Lift 开启且按住对应 Start/Select 时生效 |
| `274` | 1P 轨道遮挡启用 |
| `275` | 2P 轨道遮挡启用 |

## 数值 `num`

| 编号 | 含义 | 适用范围 |
| --- | --- | --- |
| `201` | 1P 命中偏移，单位 ms | 游玩 |
| `210` | 1P FAST/SLOW | 游玩 |
| `211` | 2P FAST/SLOW | 游玩 |
| `212` | 1P Fast 次数 | 游玩、结果；连续曲结果使用累计值 |
| `213` | 2P 命中偏移，单位 ms | 游玩 |
| `214` | 1P Slow 次数 | 游玩、结果；连续曲结果使用累计值 |
| `216` | 1P Combo Break 次数 | 游玩、结果；连续曲结果使用累计值 |
| `217` | 1P 总音符数，对应 `totalnotes` | 游玩 |
| `218` | 1P 已处理音符计数，对应 `note_current` | 游玩、结果 |
| `295` | 1P 随机排列 | 随机排列扩展 |
| `418` | 2P 随机排列 | 随机排列扩展 |
| `421` | 1P Lift 数值，范围 0–100，仅 Lift 开启时绘制 | Lift 扩展 |
| `422` | 2P Lift 数值，范围 0–100，仅 Lift 开启时绘制 | Lift 扩展 |

编号 `201`、`210`–`218` 在其他场景可能复用为 IR 统计。扩展数值须结合场景解释，不能作为全局固定含义使用。

## 滑块 `slider_type`

| 编号 | 含义 |
| --- | --- |
| `27` | 1P Lift 遮挡范围 |
| `28` | 2P Lift 遮挡范围 |

以上滑块仅在 Lift 开启时生效，`op2` 表示用于音符偏移计算的轨道高度。

## 兼容来源

Base LR2 接口、LR2 Fast/Slow 扩展、LR2OOL、beatoraja 及 OpenLR2 自有扩展共同构成当前兼容范围。扩展编号须逐项验证，不推定不同引擎间完全一致。

传统接口可参考 [英文皮肤文档](https://lr2skinhelp.vercel.app/) 与 [日文皮肤文档](https://right-stick.sub.jp/lr2skinhelp.html)。
