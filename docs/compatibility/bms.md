# BMS 扩展参考

本文记录当前 OpenLR2 源码继承的扩展接口。命令存在不代表所有组合均已通过测试；验证范围见 [兼容性与质量标准](quality.md)。

## Base62 索引

```text
#BASE 62
```

将对象索引从 Base36 切换为 Base62，可用的非零索引数量由 1,295 扩展至 3,843。大小写参与索引区分；解析、资源定义和事件引用须使用相同基数。

该扩展源自 beatoraja 0.8.8 的对应能力，现有源码包含处理路径。

## SCROLL 事件

```text
#SCROLLxx nnn
#xxxSC:...
```

`xx` 为滚动倍率定义索引，`nnn` 为倍率；事件通道引用已定义倍率，用于在不改变 BPM 的情况下调整音符滚动速度。验收须分别检查显示滚动与判定时间，不能将滚动倍率作为 BPM 变化处理。

现有扩展说明将该能力关联至 Bemuse v1.0.0-beta.18。负值、零值、连续事件及与 STOP/BPM 的组合须纳入兼容样本。

## 范围边界

本文不定义完整 BMS 语法。传统命令、长押规则、随机分支和 BMSON 由各自解析规范及版本管理；BMSON 目前属于待实现范围。
