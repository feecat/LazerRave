DX Library (DxLib)
==================

Component:   DX Library (DxLib), including the custom archive (DXA) reading code
Version:     DxLib 3.24f based, derived from 3.01a
Author:      Takumi Yamada (山田 巧)
Location:    src/OpenLR2/dep/DxLib/
Used by:     OpenLR2 (native BMS gameplay engine)

This project does not own DxLib. DxLib is free to use, including for commercial
and corporate use, and no licence fee is charged for software built with it.
DxLib is not an open-source library and its source remains the property of the
author.

Upstream terms: https://dxlib.xsrv.jp/dxlicense.html
(日本語)        https://dxlib.xsrv.jp/
