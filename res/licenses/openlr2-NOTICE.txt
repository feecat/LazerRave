OpenLR2
=======

Component:   OpenLR2, a source-rewritten BMS player engine derived from
             Lunatic Rave 2
Upstream:    https://github.com/GOMazk/OpenLR2
Location:    src/OpenLR2/
Used by:     LazerRave as the native BMS gameplay engine

Reproduced here as a reduced snapshot without a nested Git repository. See
src/OpenLR2/README.md for upstream build instructions and the list of libraries
it was derived against.

Licence status: not stated by upstream
--------------------------------------

At the time this notice was written, the upstream OpenLR2 repository publishes
no licence file and GitHub reports no declared licence for it. The vendored copy
in this repository therefore carries no licence text either.

This is an unresolved question for this project, not a settled permission.
OpenLR2 is described by its author as "rewritten source code of bms player
Lunatic Rave 2" (https://github.com/GOMazk/OpenLR2). Lunatic Rave 2 is a
closed-source commercial-era Japanese BMS player, and OpenLR2's README
references a Ghidra decompiler archive. The provenance and the terms under which
this code may be redistributed have not been established.

Consequences
------------

Redistribution of this directory may not be permitted. Before this repository or
any build containing OpenLR2 is published, distributed or commercially
shipped, the following must be established:

  1. The licensing terms that apply to GOMazk/OpenLR2.
  2. Whether those terms permit redistribution, including in source form.
  3. Whether the code's relationship to Lunatic Rave 2 imposes any further
     restriction.

Until that is resolved, treat src/OpenLR2/ as carrying unknown redistribution
terms. The MIT licence of LazerRave does not extend to it.
